# Actividad_4
Este repositorio almacena cuadernos jupyter de actividades realizadas en el curso de Programación para la Analítica de Datos 2026-2 de la Universidad Central

El objetivo es fortalecer progresivamente el manejo de la lógica de programación y de las principales herramientas utilizadas para trabajar con datos.

## Contenido

Los ejercicios abarcan temas como:

- Fundamentos y sintaxis básica de Python.
- Estructuras de control y ciclos.
- Listas, tuplas y diccionarios.
- Creación y uso de funciones.
- Operaciones básicas con NumPy.
- Manejo de Series y DataFrames con Pandas.
- Filtrado y selección de datos.
- Creación de columnas derivadas.
- Agrupación de información y cálculo de indicadores.

## Herramientas utilizadas

- Python
- NumPy
- Pandas
- Jupyter Notebook / Google Colab

## Propósito

Estos notebooks hacen parte del proceso de aprendizaje de **Programación para Analítica de Datos**, avanzando desde conceptos básicos de programación hasta la manipulación, transformación y análisis de conjuntos de datos.
